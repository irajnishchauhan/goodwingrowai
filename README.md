# Goodwin Business OS

## Overview

Goodwin Business OS is a comprehensive, production‑ready ERP system for **Goodwin Batteries**. It integrates CRM, sales, inventory, finance, after‑sales, marketing, and AI‑driven automation into a single, premium web application.

## Tech Stack

- **Frontend**: Next.js (React) with TypeScript
- **Backend**: NestJS (Node.js) with TypeScript
- **Database**: PostgreSQL (managed via Prisma ORM)
- **Containerisation**: Docker & Docker‑Compose (PostgreSQL, Redis, Mailhog)
- **Authentication**: JWT with refresh tokens
- **CI/CD**: GitHub Actions (lint, test, build, deploy to Vercel)

## Getting Started (Development)

1. **Clone the repository**
   ```bash
   git clone <repo-url>
   cd "Goodwin Business OS"
   ```
2. **Create a local `.env`** based on `.env.example`
   ```bash
   cp .env.example .env
   ```
   Adjust the values if needed (e.g., DB credentials).
3. **Start development services**
   ```bash
   docker-compose up -d
   ```
4. **Install dependencies**
   ```bash
   # Backend
   cd backend && npm install
   # Frontend
   cd ../frontend && npm install
   ```
5. **Run database migrations**
   ```bash
   cd ../backend
   npx prisma migrate dev --name init
   ```
6. **Start the API**
   ```bash
   npm run dev
   ```
7. **Start the Next.js app**
   ```bash
   cd ../frontend
   npm run dev
   ```
8. Open the app at `http://localhost:3000` and the API at `http://localhost:4000`.

## Scripts

- `npm run dev` – Start NestJS server in watch mode.
- `npm run lint` – Run ESLint.
- `npm run test` – Run Jest unit tests.
- `npm run prisma:generate` – Generate Prisma client.
- `npm run prisma:migrate` – Run migrations.
